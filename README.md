# ☕ Latteh Cafe (لاتيه ليستر) - Official Store QR Code Digital Menu

A React application for **Latteh Cafe (لاتيه ليستر)** with a single unified QR code for the entire shop. Customers scan the QR code at the counter or entrance with their smartphone camera to instantly browse the 80-item menu and submit counter pickup orders.

---

## 🌟 Key Features

### 1. 📱 One Official Store QR Code
- **Single QR Code for the Entire Shop**: No table numbers or table management needed.
- **Counter Stand & Poster Card**: Beautifully branded counter stand template with the Latteh emblem logo and instructions.
- **Instant Actions**:
  - **Print Counter Stand**: Ready-to-print luxury card for your counter or front glass.
  - **Download QR Image**: Download the SVG/PNG QR code for your social media or print flyers.
  - **Copy Menu Link**: Share the direct link on Instagram or WhatsApp.

### 2. 📋 Complete 80-Item Menu from the Board
Every item and exact price (in SAR / ر.س) transcribed directly from your menu image:
- **Hot Coffee (قهوة ساخنة)**: 22 items
- **Cold Drinks & Mojitos (مشروبات باردة وسلاش)**: 13 items
- **Fresh Juices (عصائر فريش)**: 7 items
- **Specialty Tea (شاي ومشروبات دافئة)**: 12 items
- **Desserts & Bakery (الحلويات والمخبوزات)**: 13 items
- **Cold Coffee (قهوة باردة)**: 13 items

### 3. 🌐 Full Bilingual Support
- Arabic (العربية) with Cairo font and RTL layout.
- English (EN) with Outfit font and LTR layout.
- Dual Mode (عربي / EN) showing both languages simultaneously.

### 4. 🎨 Dual Viewing Experience
- **Modern Interactive Cards**: Food photography, dietary tags, calorie counts, search, and category pills.
- **Original Board Replica View**: Recreates the two-column physical board layout from your photo.

### 5. 🛠️ Customization & Counter Pick-up
- Customization modal (sugar, milk type, ice level, extra espresso shots).
- Customer name input for order pickup calling.
- Direct WhatsApp order generation formatted for the barista.
- Digital order ticket with receipt and verification QR code.

---

## 🚀 Running the App
```bash
# Start development server
npm run dev

# Build for production
npm run build
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.
